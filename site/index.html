Typed props, live output

Every sign exposes typed props for its MUTCD code, checked at compile time. Change a value and the SVG re-renders instantly.

Measured against the rulebook

Sign geometry is traced from the official FHWA 2024 Standard Highway Signs artwork, and every template is verified with a pixel-level diff against it: gray in the overlay means agreement. The slight hue difference is expected. The official files use print CMYK conversions while mutcd-ts uses the Pantone colors the spec defines, so the diff compares by sign color class.
